# KIRILL KATIN — обновлённое портфолио

Тёплая редакционная эстетика, крупная типографика, оранжевый акцент и фотографии работ. Все 19 исходных JPEG сохранены без изменений. Контакты, внешние ссылки, кейсы и переключение RU/EN сохранены.

## Как открыть

Распакуйте архив и откройте `index.html` в браузере. Сайт работает без сборки, установки пакетов и внешних библиотек.

Для локального сервера и поддержки копирования email:

```sh
python -m http.server 8080
```

Откройте http://localhost:8080.

## Как загрузить на Vercel

Замените файлы в существующем репозитории содержимым этой папки. `index.html`, `styles.css`, `motion.js` и папка `images` должны находиться в корне репозитория.

Настройки: Framework Preset — **Other**; Build Command — пустой; Output Directory — корень проекта. После обновления подключённого репозитория Vercel выполнит новый деплой.

## Что добавлено

- Коллаж из работ, который реагирует на курсор, вращающийся графический символ и бегущая строка.
- Появление блоков при прокрутке и анимации карточек при наведении.
- Фильтры проектов: все работы, брендинг, digital и AI.
- Полноэкранная галерея: стрелки клавиатуры, Escape, свайпы и возврат фокуса.
- Раскрывающиеся блоки опыта работы и копирование email.
- Мобильная адаптация, клавиатурная навигация и учёт системной настройки уменьшения анимаций.
- Запоминание выбранного языка.

## Где редактировать

- `index.html`: проекты, контакты, опыт и основные переводы.
- `styles.css`: визуальная система, адаптив и CSS-анимации.
- `motion.js`: интерактивность и переводы новых блоков.

## Проверка

Проверены синтаксис JavaScript, локальные ссылки, уникальность идентификаторов и сохранность всех изображений по SHA-256. Визуальная и интерактивная проверка в браузере в рабочей среде оказалась недоступна; перед публикацией откройте сайт на компьютере и телефоне.

В исходном тексте были математически некорректные формулировки «сокращение расходов на 1000%». Они заменены на описание оптимизации производства; остальные показатели оставлены из исходника. Внешние страницы проектов могут изменяться независимо от репозитория.
